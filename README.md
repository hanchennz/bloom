# Bloom

Bloom is a warm, private relationship companion designed to help people remember the people who matter most. This repository contains the public landing page.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The site is statically exported to `out/` and deployed to GitHub Pages whenever `main` is updated.

## Design

The visual system uses warm cream, coral, sunflower yellow, sage, and dusty lavender, with rounded typography and an original garden mascot. It intentionally avoids social-media conventions such as feeds, likes, and streaks.
